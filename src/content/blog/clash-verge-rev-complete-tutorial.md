## 为什么 Clash Verge Rev 是目前电脑端的首选？

自 2023 年原版 Clash for Windows (CFW) 停止维护后，**Clash Verge Rev**（基于开源社区持续维护的 Mihomo / Clash Meta 内核）已成为 Windows 与 macOS 平台最主流的规则代理客户端。

相比传统客户端，它的核心优势在于：
- **开源、无内置广告、高频率维护更新**；
- **原生支持 VLESS、Hysteria2、Trojan、Shadowsocks 等现代化协议**；
- **内置一键 TUN 虚拟网卡模式**，无需额外配置系统代理即可接管终端、Git、游戏及虚拟机流量。

## 详细配置步骤（四步轻松搞定）

### 第一步：下载与安装
请前往官方开源发布仓库下载对应操作系统的安装包：
- **Windows 用户**：下载 `.msi` 或 `x64-setup.exe` 安装包安装；
- **macOS 用户**：如果是 Apple Silicon (M1/M2/M3/M4) 芯片，请务必选择带有 `aarch64` 标识的 DMG 文件。

### 第二步：导入机场订阅链接
1. 登录您所使用的机场后台（如 [光速云](/works/guangsu/) 或 [暮光加速](/works/muguang/)）；
2. 找到「快捷导入」或「复制 Clash 订阅链接」；
3. 打开 Clash Verge Rev，点击左侧菜单栏的 **「订阅 (Profiles)」**；
4. 在顶部输入框粘贴订阅链接，点击 **「导入 (Import)」**，等待进度条完成后点击该配置文件激活。

### 第三步：选择代理节点与分流模式
1. 切换至左侧 **「代理 (Proxies)」** 页面；
2. 顶部模式选择 **「规则 (Rule)」**，这样国内网站（如百度、淘宝）直连不消耗流量，国外网站与流媒体走专线节点；
3. 在节点列表中选择延迟较低的近端专线节点（如香港、台湾、新加坡、日本节点）。

### 第四步：开启系统代理或 TUN 模式
- **普通网页浏览**：在「设置」中勾选开启 **「系统代理 (System Proxy)」** 即可；
- **需要加速 Steam、Git 终端或游戏**：建议在设置中开启 **「TUN 模式 (TUN Mode)」**（需首次授权管理员权限安装虚拟网卡驱动）。

## 常见故障排查（FAQ）

#### Q: 导入订阅提示“网络请求失败 / Fetch Error”？
> **答**：通常是因为当前网络环境无法直接连接机场订阅服务器。可先开启临时代理，或在浏览器中打开订阅链接确认是否能正常下载 YAML 内容，若不能请联系服务商工单更换订阅域名。

#### Q: 网页能打开，但终端或部分游戏无法走代理？
> **答**：系统代理仅对支持系统全局 HTTP 代理的应用程序生效。请在 Clash Verge Rev 设置中安装服务模式并开启 **TUN 模式**，即可无缝透明接管全系统所有进程的 TCP/UDP 流量。
